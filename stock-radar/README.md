# KR Stock Radar v1

한국 주식 장중 돌발신호 탐지기입니다. **자동매매는 하지 않고 탐지·점수화·알림만** 수행합니다.

## 목표

- 장전 08:40 후보는 ChatGPT 자동 브리핑으로 준비
- 장중에는 한국투자증권 Open API를 1분 단위로 스캔
- 거래량/거래대금 급증 + 관심종목 상위 + 외인/기관 + VWAP + 프로그램매매를 합산 점수화
- 이미 +15~20% 급등한 종목은 감점
- +2~7% 구간에서 돈이 막 들어오는 종목을 우선 탐지
- 신호 발생 시 웹훅으로 외부 알림 전송 가능

## 공식 데이터

한국투자 Open API의 다음 기능을 사용합니다.

- 거래량순위
- 등락률 순위
- 관심종목등록 상위
- 국내기관/외국인 매매종목 가집계
- 주식현재가
- 종목별 프로그램매매추이

## 점수 핵심

- 거래대금 1,000억원+: +25
- 거래대금 500억원+: +18
- 거래량 급증: 최대 +20
- 주가 +2~7%: +18
- 관심종목 상위10: +12
- 거래량/대금 상위10: +10
- 외인·기관 순매수상위: +12
- VWAP 위: +12
- 프로그램 순매수: +8
- +15% 이상 급등: -25

기본 알림 임계값은 70점입니다.

## 배포

이 폴더를 Vercel 프로젝트의 Root Directory로 지정합니다.

환경변수:
- KIS_APP_KEY
- KIS_APP_SECRET
- KIS_BASE_URL (기본값 실전 URL)
- RADAR_ALERT_SCORE (기본 70)
- ALERT_WEBHOOK_URL (선택)
- ALERT_WEBHOOK_BEARER (선택)

**실제 APP KEY/SECRET은 GitHub에 커밋하지 말고 Vercel Environment Variables에만 저장하세요.**

## 주기

vercel.json은 한국시간 장중을 커버하도록 UTC 기준 1분 Cron을 등록하고, 함수 내부에서 KST 08:40~15:35 이외에는 자동 종료합니다.

> Vercel의 1분 Cron 주기는 요금제에 따라 제한될 수 있습니다. 지원되지 않는 요금제라면 별도 상시 실행 환경에서 같은 scanner를 실행해야 합니다.

## 한계 / v2

- 현재 버전은 REST 기반 1분 탐지입니다.
- 1분보다 빠른 틱/체결강도 돌발 포착은 KIS WebSocket 상시 연결 프로세스가 필요합니다.
- KIS WebSocket은 계좌당 동시 등록 한도가 있으므로 랭킹으로 후보 20~40개를 먼저 좁힌 뒤 실시간 구독하는 구조가 적합합니다.
- 검색순위 급상승은 KIS 관심종목등록 상위를 보조지표로 사용합니다. 네이버 검색순위 자체는 별도 합법적 데이터 소스가 연결될 때만 추가합니다.
