# KR Stock Radar v2 — Kiwoom

키움증권 REST API + WebSocket 기반 국내주식 돌발신호 탐지기입니다.
**주문/자동매매 코드는 포함하지 않습니다. 조회·탐지·알림 전용입니다.**

## 현재 구조

1. 08:40 ChatGPT 자동 브리핑: 장전 스윙 + 당일 후보
2. Kiwoom REST 랭킹 스캔: 거래량급증, 거래대금상위, 실시간종목조회순위, 예상체결, 외국인/기관, 프로그램순매수
3. 상위 후보 최대 200종목을 Kiwoom WebSocket으로 실시간 구독
4. 주식체결(0B) + 종목프로그램매매(0w)에서 체결강도, 동시간 거래량 비율, 당일 평균가, 프로그램 순매수를 계산
5. 점수 임계치 통과 시 웹훅 알림

## 돌발신호 핵심

- 주가 +2~7%: 과열 전 구간 가점
- 전일 동시간 대비 거래량 200~300%+: 가점
- 체결강도 115/130+: 가점
- 당일 평균가 위: 가점
- 프로그램 순매수: 가점
- 당일 고가 1.5% 이내: 가점
- +15% 이상 급등: 강한 감점

## 키움 공식 API 사용

REST:
- ka10023 거래량급증
- ka10032 거래대금상위
- ka00198 실시간종목조회순위(30초)
- ka10029 예상체결등락률상위
- ka90009 외국인기관매매상위
- ka90003 프로그램순매수상위50

WebSocket:
- 0B 주식체결
- 0w 종목프로그램매매

## 실행 환경

키움 REST API는 App Key 발급 시 **허용 IP 등록**이 필요합니다.
따라서 변동 egress IP를 쓰는 일반 서버리스보다 **고정 공인 IP가 있는 VPS/서버**에서 실행하는 것이 안전합니다.

1. 키움 REST API 사용 신청
2. 실전 App Key / App Secret 발급
3. 실행 서버의 고정 공인 IP를 키움 포털에 등록
4. 서버 환경변수에 KIWOOM_APP_KEY / KIWOOM_APP_SECRET 등록
5. npm install
6. npm run scan
7. npm run watch

키는 GitHub에 커밋하거나 채팅에 붙여넣지 마세요.

## 운영 제한

키움 공식 안내 기준 국내주식 조회 TR은 계좌/토큰당 초당 5회입니다.
본 스캐너는 요청 사이 최소 220ms 간격을 강제합니다.
실시간은 세션당 최대 200종목, 국내주식 실시간 조건검색은 세션당 최대 10건입니다.
